# 惠福星链 · 使用说明书

## 1. 系统概述

**惠福星链** 是惠州第一妇幼保健院的全病程健康协同平台，以"家庭ID"为核心，串联备孕、孕期、分娩、产后、育儿、五健管理的完整健康旅程。

### 1.1 四大核心模块

| 模块 | 名称 | 功能 |
|------|------|------|
| 惠福星盘 | 运营驾驶舱 | KPI看板、销售排行、随访监控、满意度评分 |
| 惠福时光轴 | 全流程健康档案 | 时间轴浏览、报告汇聚、指标趋势、异常预警 |
| 惠福灵犀 | AI智能客服 | 智能问答、意图识别、紧急预警、随访自动化 |
| 惠福同心圆 | 家庭健康账户 | 家庭ID管理、成员档案、共享权益、跨科转介 |

### 1.2 用户角色

| 角色 | 端 | 主要功能 |
|------|----|----------|
| 星球居民（孕妈/家长） | 微信小程序 | 购买服务包、查看报告、接收随访、在线咨询 |
| 医疗管家 | 企业微信 + PC | 随访执行、报告解读、转介管理 |
| 服务管家 | 企业微信 + PC | 陪诊核销、活动邀约、客情维护 |
| 医院管理者 | PC管理后台 | 数据驾驶舱、质量监管、绩效核算 |
| 荔小福运营 | PC管理后台 | 会员增长、服务包配置、活动管理 |

## 2. 快速入门

### 2.1 登录系统

1. 打开浏览器访问系统地址（由管理员提供）
2. 输入手机号和密码
3. 首次登录后建议修改密码

### 2.2 首页 — 惠福星盘

登录后默认进入运营驾驶舱，展示核心指标：
- **活跃会员**：当前活跃星球居民数量
- **本月营收**：服务包销售收入
- **随访完成率**：随访任务按时完成比例
- **满意度评分**：居民服务评价

## 3. 模块操作指南

### 3.1 惠福时光轴 — 全周期健康档案

**功能说明**：以时间轴形式展示用户的全部健康事件。

**操作步骤**：
1. 点击顶部导航「惠福时光轴」
2. 按类型筛选：产检 / 报告 / 随访 / 疫苗 / 手术 / 自测
3. 点击任一时间轴卡片查看详情
4. 异常事件（标红）优先处理

**报告查看**：
- 检验报告：指标名称、结果值、参考范围、异常标识
- 趋势图：选中指标可查看历史变化趋势
- 异常指标自动触发预警，通知对应管家

### 3.2 惠福灵犀 — 智能客服工作台

**功能说明**：AI + 人工协同的智能客服系统。

**会话管理**：
1. 左侧会话列表显示所有用户会话
2. 点击会话可查看完整聊天记录
3. 红色标识为紧急预警（关键词触发）

**智能问答**：
- AI自动回答高频问题（80%覆盖率）
- 医疗问题自动分流至医疗管家
- 权益/服务问题分流至服务管家

**紧急预警机制**：
| 关键词 | 处理方式 |
|--------|----------|
| "出血""破水""剧痛" | 10分钟内人工回电 |
| "晕倒""抽搐""呼吸困难" | 立即升级至主管 |

**随访管理**：
1. 点击「随访管理」标签页
2. 查看所有待办/进行中/已完成任务
3. 按计划日期排序，优先处理临近/逾期任务
4. 完成后填写随访备注

### 3.3 惠福同心圆 — 家庭健康账户

**功能说明**：以家庭ID为核心管理全家健康。

**家庭管理**：
1. 查看家庭信息（名称、邀请码、成员数）
2. 添加家庭成员（配偶/子女/父母）
3. 设置共享权限（全部共享 / 仅报告 / 仅基本信息）

**权益共享**：
- VVIP服务包支持家庭成员共享（如2大1小）
- 系统分别扣减每位成员的权益次数

### 3.4 系统管理

**用户管理**（管理员）：
1. 查看所有用户列表
2. 修改用户角色和状态
3. 查看数据授权状态

**服务包配置**（运营）：
1. 查看所有服务包列表
2. 设置上下架状态、价格调整

## 4. 常见操作场景

### 4.1 场景一：孕妈首次注册
1. 微信小程序扫码进入 → 手机号注册
2. 绑定家庭成员 → 创建家庭ID
3. 浏览服务包 → 选择VIP孕产套餐 → 支付
4. 授权医院数据同步 → 自动拉取产检报告

### 4.2 场景二：产检陪诊
1. 居民在小程序预约陪诊
2. 服务管家接收通知 → 产检当日全程陪同
3. 管家扫码核销陪诊权益
4. 产后报告自动同步至时光轴

### 4.3 场景三：异常指标随访
1. 糖耐量筛查结果异常 → 系统自动创建随访任务
2. 医疗管家收到待办提醒
3. 管家电话联系居民 → 解释结果 → 预约营养指导
4. 完成随访 → 记录追踪结果

### 4.4 场景四：紧急预警
1. 居民在聊天中输入"出血"
2. 惠福灵犀识别紧急关键词 → 触发预警
3. 10分钟倒计时 → 管家必须回电
4. 超时未处理 → 自动升级至主管

## 5. 注意事项

- **数据安全**：所有医疗数据访问需用户授权，系统全程记录审计日志
- **隐私保护**：云端仅存储脱敏数据（如"张*芳"），完整数据留存在院内
- **时效要求**：紧急预警10分钟响应，高危随访24小时内完成
- **权限控制**：管家仅可查看分配给自己的居民档案
