# 惠福星链 · 培训手册

## 培训对象

本手册面向以下三类培训对象：
- **医疗管家**：医院选派医护，负责随访、咨询、转介
- **服务管家**：荔小福派驻，负责陪诊核销、活动邀约、客情维护
- **管理员**：医院管理者 + 荔小福运营团队

---

## 第一课：平台认知（30分钟）

### 1.1 惠福星链是什么

惠福星链 = **医院数字化延伸** + **家庭健康管家** + **智能AI助手**

| 对比传统模式 | 传统模式 | 惠福星链 |
|-------------|----------|----------|
| 孕妈体验 | 每次产检排队挂号 | 管家陪诊 + 自动推送报告 |
| 出院后管理 | 患者自行判断 | 系统自动随访 + 异常预警 |
| 家庭覆盖 | 仅服务孕妈本人 | 以家庭ID覆盖全家 |
| 数据利用 | 纸质/分散 | 全量同步 + 异常标红 + 趋势分析 |

### 1.2 四个核心模块速览

- **惠福星盘** → 看数据，管运营
- **惠福时光轴** → 看档案，跟病程
- **惠福灵犀** → 做客服，做随访
- **惠福同心圆** → 管家庭，分权益

## 第二课：医疗管家操作（60分钟）

### 2.1 工作台日常

每天打开企业微信进入惠福星链工作台：

**待办清单**：
1. 查看待办随访任务（优先处理"高危""逾期"）
2. 查看会员动态（新注册、新购买、新预警）
3. 查看聊天消息（医疗咨询、紧急预警）

### 2.2 随访操作流程

```
收到随访任务 → 查看居民档案 → 执行随访（电话/企微/见面）
                                    │
                    ┌───────────────┼───────────────┐
                    ▼               ▼               ▼
              状况良好          需要转介         异常危急
          填写随访记录      转介至目标科室      立即上报主管
          标记已完成        记录转介奖励      创建紧急工单
```

### 2.3 报告解读要点

1. 在惠福时光轴找到异常标红的报告
2. 查看异常指标的具体数值和参考范围
3. 对比历史趋势（上升/下降/波动）
4. 电话联系居民解读结果
5. 必要时创建营养/专科转介

### 2.4 常见随访话术

**孕周随访**：
> "您好，我是您的医疗管家陈医生。根据您的孕周，这周需要关注胎动频率和血糖控制。您最近的糖耐量结果在临界值，建议您..."

**产后随访**：
> "恭喜您顺利分娩！现在是产后第6周，建议这几天来院做产后42天复查..."

**异常指标随访**：
> "您的最近一次检验报告显示XX指标偏高，不过不用太担心，我帮您预约了营养科下周二的号..."

## 第三课：服务管家操作（45分钟）

### 3.1 核销操作

**扫码核销流程**：
1. 居民出示核销二维码（小程序 → 我的权益）
2. 服务管家扫码
3. 确认权益类型（陪诊/咨询/检查/活动）
4. 执行核销
5. 系统自动扣减剩余次数

### 3.2 陪诊服务标准

**首次陪诊**（重要）：
- 提前15分钟到院等候
- 确认检查项目清单
- 全程陪同：挂号 → 看诊 → 检查 → 取药
- 结束后确认下次就诊时间

### 3.3 活动管理

1. 查看活动日历（星球活动模块）
2. 签到：用户出示签到码 → 扫码确认
3. 记录活动参与情况 → 计入积分

---

## 第四课：管理员操作（45分钟）

### 4.1 数据驾驶舱（惠福星盘）

**关注指标**：
- 活跃会员数 → 增长曲线 → 判断运营效果
- 服务包销售排行 → 哪些套餐热销
- 随访完成率 → 管家工作量分配是否合理
- 满意度评分 → 服务质量监控

### 4.2 用户管理

1. 查看全部用户 → 按角色筛选
2. 修改用户状态（正常/停用）
3. 修改用户角色
4. 查看审计日志（所有操作可追溯）

### 4.3 服务包配置

1. 创建新服务包（名称/价格/权益/有效期）
2. 设置上下架状态
3. 调整折扣价格
4. 管理权益明细

## 附录：常见问题

**Q: 居民未授权数据同步怎么办？**
A: 提醒居民在「我的 → 隐私设置」中开启数据授权，说明授权后可以自动拉取医院报告。

**Q: 家属想查看孕妈的报告需要什么条件？**
A: 孕妈在同心圆中将配偶设为"全部共享"权限。

**Q: 异常指标但居民说没事怎么处理？**
A: 记录居民反馈，但仍标记随访完成并注明"居民自主拒绝进一步检查"，系统保留记录。

**Q: 紧急预警10分钟内联系不到居民怎么办？**
A: 升级至主管 → 尝试联系紧急联系人（同心圆中的配偶/父母）→ 仍无法联系则记录工单持续跟进。
